# 打烊剩餘提醒（iPhone 捷徑＋LINE）：設定步驟

管理者的 iPhone 每天 **20:00**、**20:20** 自動問一次「今天打烊剩餘填了沒」：

- **還沒填**：拿到提醒文字，用 LINE 發到員工群組。
- **已填好或公休**：拿到空白，就不發。

訊息是管理者本人發的，**不需要 LINE 官方帳號，也不算則數**。

```
🔔 打烊囉！請填 11/17(二) 的打烊剩餘
還沒填：🍗 雞肉、🍕 餅皮
👉 https://jane3377.github.io/Scheduling_Cai/index.html?go=stock
```

20:20 的追蹤訊息開頭是「⚠️ 再提醒」，只列還沒填的項目。

---

## 一、Google Apps Script（約 10 分鐘）

1. 到 **script.google.com**，按「新專案」，專案名稱改成「比薩屋剩餘提醒」。
2. 刪掉預設的程式碼，貼上 `Code.gs` 的完整內容，按 💾 儲存。
3. 設密碼：左邊 ⚙「專案設定」→ 最下面「指令碼屬性」→ 新增：
   - 屬性：`API_KEY`
   - 值：自己取一串英數字，例如 `pizza7x9k2m`，不要用生日
4. 同一頁的「時區」選 **(GMT+08:00) 台北**。
5. 先測試：編輯器上方函式選 `testStatus` → 按「執行」。
   - 第一次會要求授權：用 Google 帳號同意。看到「Google 尚未驗證」時，點「進階」→「前往…」。
   - 「執行記錄」會顯示今天雞肉、餅皮填了沒，以及捷徑會拿到的文字。
6. 發布成網址：右上「部署」→「新增部署作業」→ 齒輪選「**網頁應用程式**」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製網址（結尾是 `/exec`）
7. 用瀏覽器打開下面這個網址，確認看得到提醒文字。已填好時會是空白頁。
   ```
   <剛才的網址>?k=<你的密碼>&stage=first
   ```

> 之後改了 `Code.gs`，要按「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→ 部署。網址不會變。

## 二、iPhone 捷徑

（等管理者測完「LINE 的捷徑動作能不能直接發到群組、會不會跳確認」，再補上詳細步驟。）

大致流程：
1. 「捷徑」App →「自動化」→ 新增 →「特定時間」20:00、每天、**立即執行**。
2. 動作：
   - 「取得 URL 內容」：`<網址>?k=<密碼>&stage=first`
   - 「如果」上一步的內容**有任何值**：用 LINE 傳送該內容到員工群組
3. 再建一個 20:20 的自動化，網址改成 `stage=follow`。

## 常見問題

- **Firebase 讀取量**
  - 只有捷徑呼叫時才讀，每次 1～2 次，一天最多 4 次。
  - Firebase 免費額度是每天 50,000 次。
- **密碼外洩**
  - 別人頂多看到「今天剩餘填了沒」，不能改任何資料。
  - 到「指令碼屬性」換一組新密碼，再更新捷徑的網址即可。
- **Firebase 讀取失敗（403）**
  - 確認 Firebase「Authentication → 登入方式」有開啟**匿名**。網站本來就在用。
  - 如果在 Google Cloud 對 API 金鑰設了「網站限制」，要放寬，或另外建一把金鑰給它用。
- **管理者手機沒開機**：當天就不會發。這是用個人手機發送的限制。

## 搬家到業主帳號時要改的地方

1. 用業主的 Google 帳號重做「一」，再共用給你編輯。
2. `Code.gs` 最上面 `CONFIG` 的三個值改成新的：
   - `FIREBASE_API_KEY`、`FIREBASE_PROJECT_ID`：跟網站 `js/firebase-config.js` 一樣
   - `STAFF_URL`：新的員工頁網址＋`?go=stock`
3. 捷徑裡的網址換成新的 `/exec` 網址。
